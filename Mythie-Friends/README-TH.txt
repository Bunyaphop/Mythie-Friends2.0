Mythie Friends — โปรเจกต์สำหรับ VS Code

วิธีเปิดแก้ไข
1. แตกไฟล์ ZIP ทั้งหมดก่อน
2. เปิด VS Code เลือก File > Open Folder แล้วเลือกโฟลเดอร์ Mythie-Friends
3. เปิดไฟล์ที่ต้องการแก้ไข แล้วกด Ctrl+S เพื่อบันทึก

วิธีเล่น
เปิด index.html ด้วย Chrome หรือ Edge ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือเซิร์ฟเวอร์
เมื่อแก้โค้ดแล้ว ให้บันทึกและรีเฟรชหน้าเบราว์เซอร์
ต้องเก็บ index.html, style.css, script.js และ assets ไว้ด้วยกันตามโครงสร้างเดิม

ไฟล์ในโปรเจกต์
index.html = โครงสร้างหน้าเว็บ
style.css = สี ฟอนต์ ขนาด การจัดวาง และภาพประกอบ
script.js = กติกาเกม เลเวล อนิเมชัน และลากวาง
assets/ = ภาพตัวละคร อาหารเดิม และอาหารใหม่ 3 อย่าง

จุดแก้ไขหลักใน script.js
CHARACTERS = รายชื่อตัวละครและอาหารประจำตัว
FOODS = ชื่ออาหารและตำแหน่งภาพ
feedPlan = จำนวนสัตว์และตัวเลือกอาหารของแต่ละเลเวล
shadowCount = จำนวนคู่เงาของแต่ละเลเวล
moveToShadow = อนิเมชันย้ายตัวละครไปยังเงา

รูป characters.png เป็นภาพรวม 8 ตัว (4 คอลัมน์ 2 แถว)
รูป original-foods.png เป็นภาพรวมอาหารเดิม 5 อย่าง (3 คอลัมน์ 2 แถว)
ตัวเกมใช้ CSS เลือกแสดงแต่ละช่องของภาพรวม จึงควรรักษาตำแหน่งในภาพไว้เมื่อเปลี่ยนรูป

ทุกเกมมี 10 เลเวล เกมให้อาหารมีเลเวลละ 2 ด่าน
เลเวลให้อาหาร 1–2: 1 ตัว / 2 ตัวเลือก, 3–4: 1 / 3,
5–6: 2 / 3, 7–8: 2 / 4, 9–10: 3 / 3

ถ้าไม่เห็นอนิเมชัน ให้ปิด Reduce movement ใน Settings
และตรวจการตั้งค่าลดการเคลื่อนไหวของระบบปฏิบัติการ
