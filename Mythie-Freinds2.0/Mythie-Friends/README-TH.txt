Mythie Friends — 40-Level Edition

วิธีเปิด
แตก ZIP แล้วเปิดโฟลเดอร์ Mythie-Friends ใน VS Code
เปิด index.html ในเบราว์เซอร์ได้โดยตรง หรือใช้ Live Server
หากนำชุดนี้ขึ้น GitHub ให้อัปโหลดทุกไฟล์พร้อมโฟลเดอร์ assets โดยรักษาโครงสร้างเดิม
ไฟล์ index.html แบบรวมที่ให้ดาวน์โหลดแยกต่างหาก ใช้อัปโหลดแทนไฟล์เดิมเพียงไฟล์เดียวได้

จำนวนเลเวล
จับคู่เงา 20 เลเวล + ให้อาหาร 20 เลเวล = 40 เลเวล
ให้อาหารมี 2 ด่านย่อยต่อเลเวล จึงมีโจทย์รวม 60 รอบต่อการเล่นครบหนึ่งครั้ง

แผนความยาก (ตัวละคร / ตัวเลือก)
เลเวล      จับคู่เงา       ให้อาหารต่อด่านย่อย
1–4        1 / 3          1 / 2
5–8        2 / 3          1 / 3
9–12       2 / 4          2 / 3
13–16      3 / 4          2 / 4
17–20      4 / 5          3 / 5
ตั้งแต่เลเวล 9 ระบบจะให้ความสำคัญกับตัวหลอกในกลุ่มรูปร่างใกล้กัน
ไม่จับเวลา ตอบผิดลองใหม่ได้ มีคำใบ้ และเลือกเล่นได้ทุกเลเวล

ระบบสุ่ม
- สุ่มตัวละครเป้าหมาย ตัวหลอก และตำแหน่งคำตอบเมื่อเริ่มเลเวลหรือเล่นอีกชุด
- ให้น้ำหนักกับตัวละครที่เพิ่งปรากฏน้อย เพื่อให้พบเพื่อนครบทั้ง 8 ตัว
- หลีกเลี่ยงชุดเป้าหมายเดิมจากการเล่นเลเวลนั้นครั้งก่อนและรอบล่าสุดของเกม
- แต่ละตัวมีอาหารประจำตัวเหมือนเดิม และต้องการเพียง 1 อย่าง
- เกมให้อาหารใช้เป้าหมายต่างกันในสองด่านย่อยของเลเวลเดียวกัน
- พักเกม เปลี่ยนภาษา และเปลี่ยนค่าตั้งไม่สุ่มโจทย์ใหม่
- Restart level ในเมนูพักเกมเริ่มเลเวลใหม่ด้วยโจทย์สุ่มใหม่

ความคืบหน้า
- หน้าแรกแสดงความคืบหน้าแยกเกม 0/20 และปุ่มเล่นต่อ
- เล่นต่อเริ่มที่เลเวลแรกที่ยังไม่ผ่าน ไม่ใช่การคืนสถานะกลางด่านหลังปิดเบราว์เซอร์
- เล่นอีกชุดหลังจบเลเวลสุ่มโจทย์ใหม่ที่ความยากเดิม ไม่ล้างความคืบหน้า
- เมื่อผ่านครบ 40 เลเวล ปุ่มเริ่มการผจญภัยใหม่ปรากฏที่หน้าแรกและหน้าจบเลเวล
- ต้องยืนยันก่อนรีเซ็ต เครื่องหมายผ่านของทั้งสองเกมจะถูกล้าง
- รีเซ็ตเก็บค่าภาษา เสียง การเคลื่อนไหว และประวัติสุ่มไว้ เพื่อหลีกเลี่ยงโจทย์ล่าสุด
- ความคืบหน้าเก่าจากรุ่น 10 เลเวลยังอยู่ในเบราว์เซอร์เดิม/เว็บไซต์เดิม

ภาษาและเสียง
ภาษาเริ่มต้น English เลือกไทยได้ใน Settings
เริ่มต้นปิดเสียงทั้งหมด เปิดเพลงและเอฟเฟกต์แยกกันได้ พร้อมปุ่มปิดเสียงทั้งหมด
เพลงและเสียงสังเคราะห์ในเกม เล่นออฟไลน์ ไม่มีไฟล์เพลงภายนอก
เสียงคลิก หยิบ วาง และตอบถูก เพลงหยุดเมื่อพักเกมหรือซ่อนแท็บ
หากเคยเปิดเสียงไว้ การกลับเข้าเกมจะรอผู้เล่นแตะ/กดปุ่มก่อนเล่นเสียง
ลดการเคลื่อนไหวได้ และรองรับการแตะอาหารแล้วแตะชามแทนการลาก

ไฟล์แก้ไข
index.html — โครงหน้า
style.css — หน้าตาและมือถือ
i18n.js — คำแปลไทย
audio.js — เพลงและเอฟเฟกต์
script.js — กติกา แผนเลเวล สุ่มโจทย์ และความคืบหน้า
assets/ — ภาพเดิมและฟอนต์ไทย (ใบอนุญาต FONT-LICENSE.txt)
